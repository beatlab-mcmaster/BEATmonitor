Acceleration Tutorial

Author

Maya Flannery

About

This tutorial will show you the steps required to read heart rate (HR) and acceleration (AC) data transferred from Bangle.js 2 smart watches running the BEATwatch application.

Prerequisites

  1. You have installed the BEATwatch application on a Bangle.js 2 smart watch.
  2. You have installed the BEATmonitor dashboard on your computer.
  3. You have recorded data with the BEATwatch app (either manually or with the dashboard).
  4. You have transferred raw watch data using the dashboard.
NoteNote:

The initial processing steps are introduced here in Python. However, the results of this processing are saved in csv format, and can be read and analysed using other languages/software.

By default, transferred data are saved in BEATmonitor/src/dashboard/watchData/transferredData/

Read data

Read all of the watch data by passing the file_summary along with the configuration (cfg) to get_raw_watch_data() (any flagged files that were dropped from the file_summary will be skipped).

df_raw = data_access.get_raw_watch_data(file_summary, cfg)
